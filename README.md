# AnimeVerse

A non-commercial personal anime catalog with Bengali/English interface, search, genre and watch-status filters, sorting, favorites, personal ratings and notes, poster cards, watch links, and an add-anime form.

## Personal data

Favorites, watch status, ratings, notes, and added titles are saved only in the visitor's own browser storage. They are not sent to a server or shared between visitors.
